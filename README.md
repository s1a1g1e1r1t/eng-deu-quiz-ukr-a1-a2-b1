# Eng-Deu Quiz (Ukrainian translations, A1–B1)

A mobile quiz app for learning English and German with Ukrainian translations, covering CEFR levels A1, A2 and B1.

Created with Google AI Studio.

## Features

- Separate sections for English and German
- Levels A1, A2 and B1
- Word guessing quiz
- Sentence building quiz
- Ukrainian translations
- Built-in AI chat assistant powered by Gemini

## How to run

This is an Android app generated with Google AI Studio.

1. Download the repository (Code → Download ZIP) and unzip it.
2. Open the folder in Android Studio and run it on a phone or emulator.

Or install the APK on an Android phone via USB.

## Notes

The AI chat requires an internet connection and a Gemini API key. The free tier has daily request limits, so the chat may stop responding after heavy use.
